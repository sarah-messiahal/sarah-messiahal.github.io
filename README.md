# Sarah Messiahal — Portfolio

Animated portfolio for a Flutter developer. Plain HTML, CSS and JavaScript (GSAP, bundled), hosted on GitHub Pages.

- `index.html` — the page
- `css/style.css` — styles and fonts
- `js/main.js` — animations (intro, scroll reveals, video autoplay)
- `assets/work/` — work videos (mp4) and their poster images
- `assets/sarah.webp` — profile photo

To update a project video, replace the matching file in `assets/work/` (same name), or add a new `<article class="case">` in `index.html`.
